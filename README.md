# בעל הסולם — כל התורה במקום אחד

ספרייה דיגיטלית של כתבי בעל הסולם, הרב יהודה לייב הלוי אשלג.

**האתר:** https://amal-ramot.github.io/baal-hasulam/

## מה יש באתר

| חיבור | עמודי לימוד |
| --- | --- |
| הסולם על ספר הזוהר | 638 |
| תלמוד עשר הספירות (עם אור פנימי, הסתכלות פנימית ולוחות השאלות והתשובות) | 368 |
| מתן תורה — קונטרסים ומאמרים | 18 |
| פתיחה לחכמת הקבלה | 9 |
| הקדמה לספר הזוהר | 5 |
| פתיחה לפירוש הסולם | 5 |
| מבוא לספר הזוהר | 3 |

- **קורא** — גודל גופן, גופן ספר/נקי, מצב כהה/בהיר, סימניות, "המשך מהמקום שעצרת", דפדוף במקשי החצים, קישור ישיר לכל אות.
- **אור פנימי בתוך הטקסט** — בתלמוד עשר הספירות לחיצה על אות הציון פותחת את הביאור המתאים.
- **חיפוש בטקסט מלא** על כל הכתבים (כ-2.7 מיליון מילים), רץ כולו בדפדפן.
- **חיפוש מהיר** (`Ctrl/⌘ + K` או `/`) לקפיצה לכל חיבור, פרשה או חלק.
- **מושגי יסוד** — אילן עשר הספירות ומילון קצר; **תולדות** — ציר זמן.

חיבורים שעדיין אינם באתר (פנים מאירות ומסבירות, פרי חכם, שמעתי ועוד) מפורטים בעמוד הספרייה.

## טכנולוגיה

Next.js 16 (App Router, React 19 Server Components) בייצוא סטטי מלא — 1,060 עמודים שנבנים מראש, ללא שרת.

```bash
npm install
npm run dev      # פיתוח — http://localhost:3000
npm run build    # ייצוא סטטי אל out/
```

- `content/` — הטקסטים המנורמלים (JSON), נוצרים ע"י `npm run content`.
- `scripts/build-content.mjs` — מוריד את המהדורות העבריות מספריא וממיר אותן לעמודי לימוד.
- `scripts/build-search.mjs` — בונה את אינדקס החיפוש אל `public/search/` (רץ אוטומטית לפני build/dev).
- `.github/workflows/pages.yml` — בנייה ופריסה ל-GitHub Pages בכל push.

## פריסה ל-GitHub Pages

הפריסה אוטומטית. בפעם הראשונה יש לוודא שב-**Settings → Pages → Build and deployment → Source** נבחר **GitHub Actions**.

## מקורות

הטקסטים מובאים בלשונם מתוך המהדורות הדיגיטליות של [ספריא](https://www.sefaria.org.il)
(זוהר עם פירוש הסולם, ירושלים תש"ה; תלמוד עשר הספירות, ירושלים תשט"ז–תשכ"ו; ספר מתן תורה).
ההסברים בעמוד המושגים ובציר הזמן הם תקציר עריכתי ואינם ציטוט.
