# בעל הסולם — כל התורה במקום אחד

ספרייה דיגיטלית של כתבי בעל הסולם, הרב יהודה לייב הלוי אשלג.

**האתר:** https://amal-ramot.github.io/baal-hasulam/

## מה יש באתר

| חיבור | עמודי לימוד |
| --- | --- |
| הסולם על ספר הזוהר | 638 |
| תלמוד עשר הספירות (עם אור פנימי, הסתכלות פנימית ולוחות השאלות והתשובות) | 363 |
| מתן תורה — קונטרסים ומאמרים | 16 |
| פתיחה לחכמת הקבלה | 9 |
| הקדמה לספר הזוהר | 5 |
| פתיחה לפירוש הסולם | 5 |
| מבוא לספר הזוהר | 3 |

- **קורא** — גודל גופן, גופן ספר/נקי, מצב כהה/בהיר, סימניות, "המשך מהמקום שעצרת", דפדוף במקשי החצים, קישור ישיר לכל אות.
- **אור פנימי בתוך הטקסט** — בתלמוד עשר הספירות לחיצה על אות הציון פותחת את הביאור המתאים.
- **חיפוש בטקסט מלא** על כל הכתבים (כ-2.7 מיליון מילים), רץ כולו בדפדפן.
- **חיפוש מהיר** (`Ctrl/⌘ + K` או `/`) לקפיצה לכל חיבור, פרשה או חלק.
- **מושגי יסוד** — 1,570 ערכי "פירוש המלות" בלשון בעל הסולם, מתוך לוחות התשובות שבתלמוד עשר הספירות; **תולדות** — ציר זמן (רקע ביוגרפי, לא מכתביו).

חיבורים שעדיין אינם באתר (פנים מאירות ומסבירות, פרי חכם, שמעתי ועוד) מפורטים בעמוד הספרייה.

## טכנולוגיה

Next.js 16 (App Router, React 19) בייצוא סטטי מלא, ללא שרת. עמודי הקריאה נטענים כקובצי נתונים קטנים (`public/data`, נבנים אוטומטית), כך שהאתר כולו שוקל כ-58MB.

```bash
npm install
npm run dev      # פיתוח — http://localhost:3000
npm run build    # ייצוא סטטי אל out/
```

- `content/` — הטקסטים המנורמלים (JSON), נוצרים ע"י `npm run content`.
- `scripts/build-content.mjs` — מוריד את המהדורות העבריות מספריא וממיר אותן לעמודי לימוד.
- `scripts/build-search.mjs` — בונה את אינדקס החיפוש אל `public/search/` ואת עמודי הקריאה אל `public/data/` (רץ אוטומטית לפני build/dev).
- `.github/workflows/pages.yml` — בנייה ופריסה ל-GitHub Pages בכל push.

## פריסה ל-GitHub Pages

הפריסה אוטומטית. בפעם הראשונה יש לוודא שב-**Settings → Pages → Build and deployment → Source** נבחר **GitHub Actions**.

## נוסח: רק דברי בעל הסולם

באתר מופיעים דברי בעל הסולם בלבד. `scripts/build-content.mjs` מסיר מן המהדורות הדיגיטליות כל מה שנוסף בידי מהדירים מאוחרים:

- הערות שוליים של עורכים (כולל "אמר העורך" והערות בשם אחרים);
- השלמות, תרגומים והפניות שנוספו בסוגריים מרובעים;
- כותרות משנה שנוספו בהקדמה לספר הזוהר ובמאמרים מתן תורה, הערבות, החירות ומאמר לסיום הזוהר;
- קישורי ניווט וסימוני הפניה של המהדורה הדיגיטלית.

שתי הערות שבעל הסולם עצמו הוסיף בכתב היד של מאמר החירות נשמרו ומסומנות "הערה בכתב היד".

מה שלא ניתן היה לבדוק מול הדפוסים הראשונים:

- **מתן תורה והקדמה לספר הזוהר** — הנוסח הזמין הוא מהדורת "זוהר הסולם" (תשע"ט). הפיסוק, הניקוד, חלוקת הפסקאות ומראי המקומות הם של המהדורה. במאמרים גילוי טפח וכיסוי טפחיים, מהות הדת ומטרתה, מהות חכמת הקבלה והשלום נשארו כותרות המשנה כפי שהן במהדורה.
- **פתיחה לחכמת הקבלה, מבוא לספר הזוהר, פתיחה לפירוש הסולם** — במהדורה הדיגיטלית עודכן הפיסוק ונפתחו ראשי תיבות.
- **תלמוד עשר הספירות** — ה"פנים" הוא לשון האר"י כפי שבחר וסידר בעל הסולם; כל השאר מאת בעל הסולם.
- **הסולם** — הפירוש בלבד; המילים המודגשות הן לשון הזוהר.

פירוט הנוסח מופיע גם בעמוד של כל חיבור ("על הנוסח").
